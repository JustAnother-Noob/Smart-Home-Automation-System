Security Best Practices

  • Rotate your administrator password every 60-90 days.
  • Use unique passwords for your admin account and avoid reuse.
  • Enable multi-factor authentication wherever possible.
  • Review admin activity in the Network Logs for unusual behavior.
  • Log out from admin sessions when not in use to prevent unauthorized access.
  • Monitor failed login attempts and implement account lockout policies.
  • Keep your browser and system updated with the latest security patches.
  • Never share admin credentials with unauthorized personnel.
